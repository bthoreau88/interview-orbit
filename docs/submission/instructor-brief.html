Limits, stated up front

  • No speech-to-text. The student types what they said, or uses a sample text that is labelled "DEMO / SAMPLE – not transcribed from this recording".
  • No server. Saved sessions live in the browser on one device. The API is specified in the data contract and marked not implemented.
  • Audio is never stored or uploaded. It exists only in the open tab for playback.
  • Not deployed yet. The existing Netlify prototype is an earlier upload and is unchanged.

90-second demonstration

  1. Open the Dashboard and press Start practice.
  2. Choose a behavioural question and allow the microphone.
  3. Record about 20 seconds, then stop.
  4. Type the answer and read the feedback and its formulas.
  5. Save, refresh the browser, and reopen the session from History.
  6. Delete it. Then deny the microphone to show the recovery screen.
